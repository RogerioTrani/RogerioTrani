# Rogério Trani

Desenvolvedor focado em automação de processos financeiros e contábeis — apuração de impostos, integração com sistemas de emissão de notas fiscais de serviço (e-NFS) e rotinas que exigem precisão e auditabilidade.

## O que estou construindo

- **[trident-loop](https://github.com/RogerioTrani/trident-loop)** — skill de código aberto (MIT) que coloca agentes de IA de provedores diferentes para revisar planos e código uns dos outros. Você escreve o plano com um agente, outro provedor revisa com evidências, um builder implementa e um terceiro inspeciona o diff final. Funciona com Claude Code, Codex, Kimi Code, DeepSeek Harness, qwen-code e OpenCode. Adaptada de [chaseai-yt/claudex-loop](https://github.com/chaseai-yt/claudex-loop).

## Como trabalho

Processos financeiros e fiscais pedem revisão em camadas, então uso agentes de vários provedores em rodadas de revisão — trocando o revisor conforme o caminho que a revisão toma, com cada achado sustentado por evidência no código.
